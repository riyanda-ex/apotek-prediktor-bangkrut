# Apotek Prediktor Bangkrut

Prediksi risiko kebangkrutan apotek 3 bulan ke depan - sebelum terlambat.

Model: **Explainable AI (Rule-Based Scoring)** - bukan black-box. Setiap skor bisa dijelaskan.

## Kenapa Apotek Bangkrut?

Dari data UMKM Indonesia, 3 penyebab utama:
1. **Kehabisan kas** - uang habis buat stok, tapi stok tidak laku
2. **Stok mati / expired** - 30-40% uang terjebak di gudang
3. **Hutang menumpuk** - ke distributor / PBF

Alat ini mendeteksi ketiganya 3 bulan lebih awal.
